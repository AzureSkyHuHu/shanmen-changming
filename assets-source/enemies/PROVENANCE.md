# Original battle enemies

Created2026-10-01 for this project by direct SVG pixel-art authorship, following the existing character pipeline. No downloaded assets, external art pack, branded character or reused third-party illustration.

- Ridge raider: masked human saber wielder, terracotta robe and wrapped steel weapon
- Venom adept: hooded human poison caster, sage robe, plum hood and paired toxin gourds
- Moss boar: slate-green tusked beast, moss crown and brass ward chain
- Ruin guardian: weathered stone temple construct, jade eyes/core, asymmetrical stone shoulders
- Ember wisp: bound ritual lantern inside a terracotta flame silhouette

The current `*-96-v2.svg` files and matching versioned runtime PNGs were newly drawn on a native96×96 integer grid on2026-10-01. They are generated by `../generate-96-art.py`, with exact576×288 sheets containing six distinct poses in front/right/back rows. Left mirrors right. No old art was upscaled; human silhouettes occupy85–88px height, boar78–80px, guardian87–88px and lantern84px. Grounded feet share `(48,91)`; the lantern has a small floating cycle within the same frame. The installed Inkscape renderer uses `--export-png-antialias=0`, preserving binary alpha and crisp1px details. No package installation.

Unversioned48×64 sources, PNGs and `generate-enemies.py` are historical comparison assets. Current runtime URLs only use the `-96-v2` version. The shared asset manifest, pixel QA report and contact/comparison proofs are under `../characters/`.

The SVG sources and PNG contact sheet establish static asset evidence only. Actual browser/Phaser animation, mobile scale and gameplay readability still require interactive visual review by the integration owner.
