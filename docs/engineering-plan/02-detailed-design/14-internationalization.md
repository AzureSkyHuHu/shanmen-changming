# DD-14 默认中文、中英切换与逐键回退

状态：设计基线 / 待评审；未实现、未执行游戏测试

需求追踪：[REQ-031](../00-overview/requirements.md#req-031)、[REQ-023](../00-overview/requirements.md#req-023)、[REQ-025](../00-overview/requirements.md#req-025)

<a id="keys"></a>
## 稳定文本键与覆盖面

zh-CN为基础语言，en为可切换语言。UI按钮/面板/菜单、建筑与资源、技能/天赋/状态、事件选项、主线、tooltip、风险说明、战斗日志、错误与帮助都使用稳定textKey。中文基表缺键是内容构建错误；英文可以暂缺，按单键回退对应中文，不能整页变空白或显示内部键。

定义持有nameKey/descriptionKey等；事件保存key+参数，展示时解析语言。持久化的实体/内容/事件ID不翻译，不用中文名称作键。用户输入姓名/自定义宗门名原样展示；默认既有专名不擅自改名，若后续人工批准英文名只在显示映射中增加。

<a id="resolve"></a>
## 解析、模板与格式

建议适配器：i18next/react-i18next，实施时锁版本。显式lng=zh-CN、fallbackLng=zh-CN、returnEmptyString=false；空英文值也必须回退。未经玩家选择不让浏览器语言覆盖默认中文，不启用网络翻译或saveMissing后端。当前只是设计建议，不安装依赖。

解析顺序：当前locale对应key→zh-CN同key→可见的中文通用错误/占位并记录本地诊断。缺中文应在构建前阻断；运行时兜底只为损坏内容恢复，不掩盖发布缺键。

模板必须完整句子并使用命名参数；禁止字符串片段拼接句子导致英语词序错误。声明参数类型与单位，数字/百分比/时长按选定locale格式化；复数使用支持语言规则的模板机制，在TASK-051选型并锁版本。中文/英文同key参数名与类型必须一致，转义用户输入，不能拼HTML。

风险与卡面数值来自同一领域查询，翻译仅改变文案，不重新计算概率或消费随机流。

<a id="switch"></a>
## 切换与持久化

语言偏好存入独立Settings，默认zh-CN；损坏设置可重置而不改战役。运行时切换使显示投影/格式缓存失效，重绘已打开面板/日志/Canvas标签；保留焦点、选中、暂停、待提交指令与offer。切换不得推进tick、重新生成世界、重抽机缘或修改战役hash。

导出战役使用稳定ID与模板参数，语言设置可单独导出但不是读档必需。中文和英文用户读取同一档得到同领域状态。旧档内若有历史纯文本需迁移策略：保留旧历史文本并标记legacy，不伪造可逆翻译。

<a id="tests"></a>
## 验收与当前交付边界

中文覆盖率100%（所有定义/界面扫描键齐全），英文缺键逐项回退；英文/中文参数集合和类型匹配；0/1/多项数量、百分比、小数、姓名含符号全部测试。实际英文长字符串和伪本地化扩展覆盖150%文字、tooltip、按钮、日志及卡面溢出。

打开战斗/offer/风险确认时切换两次，模拟状态hash、RNG状态、commandId和待选offer不变；设置读写不改战役。用户自定义姓名不翻译。当前交付的是映射架构和制作任务，未创建或声称完成全量英文翻译。
