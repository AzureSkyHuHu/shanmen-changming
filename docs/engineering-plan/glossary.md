# 术语与单位

| 术语 | 精确定义 |
|---|---|
| 宗门/sect | 跨弟子世代延续的玩家治理主体，不等于某个必然寿尽的角色 |
| character | 角色生命周期作用域，永久树只随此角色保留 |
| run/远征一局 | 推荐整趟多场战斗远征，仍待确认；由runId标识 |
| encounter/遭遇 | 一场战斗，含独立队列/状态/冷却边界 |
| tick | 权威离散逻辑步；与表现帧不同 |
| 经营月 | 年龄/生产/任务战略时间单位；12月=1年 |
| scope | 最晚在哪个生命周期边界回收，不等同持续时间 |
| duration | 提前到期的tick或节点数，可与run来源同时存在 |
| definition/instance | 可复用内容配方 / 某来源安装的具体事实 |
| owned/reserved/available | 拥有/预留/可用；available=owned−reserved |
| ActionCommitted | 前摇后重验通过，费用和正式冷却唯一提交点 |
| proc | 由事件派生的效果；默认不再次同类递归 |
| Downed/Dead | 可救援倒地 / 已提交永久死亡，不能混发奖励 |
| sourceInstanceId | 精确贡献来源，移除不得误删其他同名来源 |
| sealed/secured loot | 已封存战利品；与未封存按退出原因不同结算 |
| offer | 已生成并保存的一组三选一及持有人候选，不是每打开UI现抽 |
| 静态提升/局内倍率 | 待测试平衡指标，不是已证明的战力数字 |
| textKey | 稳定文本映射键，与实体ID/显示名分离 |
| zh-CN/en fallback | 默认中文，英文缺键或空值逐键回退中文 |
| planned/not_run | 任务未实施 / 对应游戏测试未运行；不等于失败或通过 |

秒/月/年、tick/帧、整数/百分比字段须在schema和UI声明单位。不得以现实离线时长直接推算弟子年龄或死亡。
