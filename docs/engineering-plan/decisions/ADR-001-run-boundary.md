# ADR-001-run-boundary: 整趟远征作为run

状态：proposed / 待用户确认

## 决定/建议
整趟多战斗远征作为一局，标准6次三选一；单场战斗为encounter。

## 原因与后果
可让机缘跨战斗积累与经营准备/路线选择连接。若单场即一局需重做卡池节奏、损失、scope、保存与清理。

## 复审触发
用户范围变化、原型证据否定前提，或存档/表现/内容兼容发生破坏性变更时复审。不可用后续实现便利自动覆盖玩法边界。
