# ADR-007-i18n: 默认中文与英语逐键回退

状态：requirement confirmed / 实现细节待评审

## 决定/建议
默认zh-CN，可切en；稳定textKey，en缺失逐键中文回退；参数化完整模板；语言设置独立。

## 原因与后果
是用户明确的1.0要求。增加文本覆盖、英语扩展和参数一致性测试；不改变人物自定义名、模拟状态或存档身份。

## 复审触发
用户范围变化、原型证据否定前提，或存档/表现/内容兼容发生破坏性变更时复审。不可用后续实现便利自动覆盖玩法边界。
