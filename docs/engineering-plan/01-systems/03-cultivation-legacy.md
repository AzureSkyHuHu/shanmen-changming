# 修炼、关系与跨代传承

状态：设计基线 / 待评审；未实现、未执行游戏测试

需求追踪：[REQ-009](../00-overview/requirements.md#req-009)、[REQ-010](../00-overview/requirements.md#req-010)、[REQ-011](../00-overview/requirements.md#req-011)

使命：让弟子形成个人历史，强者成长与后辈培养共用稀缺时间。

拥有：资质、修为、伤势、寿元、突破请求、师徒关系、遗物交接、死亡档案与掌门继任。

入口：修炼/授业/闭关命令及已提交事件。出口：风险预览、准备缺口、属性来源、关系原因、历史与继承事务。

关键选择：突破成功率与失败死亡率各自展示；生命周期死亡与战斗倒地分开；永久树仅对该角色永久，不能复制全部战力给接班人。

恢复策略：普通失败先给疗伤/准备路径；不可逆风险前停表和明示；全员覆灭有安全档/复兴规则，不静默删档。
