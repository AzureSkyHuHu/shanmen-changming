# 活宗门、经济与空间

状态：设计基线 / 待评审；未实现、未执行游戏测试

需求追踪：[REQ-002](../00-overview/requirements.md#req-002)、[REQ-003](../00-overview/requirements.md#req-003)、[REQ-006](../00-overview/requirements.md#req-006)、[REQ-007](../00-overview/requirements.md#req-007)、[REQ-008](../00-overview/requirements.md#req-008)

使命：人物的可见工作真正解释产出；建设空间与劳力配置形成取舍。

拥有：地图可达性、岗位/任务/入口预约、日程需求、有效工时、建筑和研究订单。动画与镜头不在本域。

入口：排班、指派、蓝图、订单、暂停和危险事件。出口：任务状态/原因、资源事务、占位变更、人物位置与动作意图。

关键选择：不逐根木材模拟；以任务物流与可达距离计费；先保证开局四人能生存，再验证36人压力。岗位与材料共享事务以避免取消时复制。

恢复策略：缺料等待、道路阻塞可诊断、伤者优先照护、低收益觅食始终可用。生产中断保留真实消耗，不能全退又保留产物。
