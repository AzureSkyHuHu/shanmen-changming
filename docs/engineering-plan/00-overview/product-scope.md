# 产品边界与交付总览

## 产品承诺
山门长明（暂名）是以宗门为延续主体的纯单人修仙经营战役。可见人物生活、生产、培养、出征构筑、伤老传承共同形成闭环；仅有资源面板与地图背景不构成完整版本。用户要求的是超过30小时开发工作量规模的项目，本包不把此要求解释成30小时游玩时长，也不承诺具体开发工期。

本阶段交付的是可放进未来代码仓库的设计文件。无游戏代码、无可运行构建、无实际性能数据、无已执行的游戏测试，未安装依赖或发布服务。后续实施须先确认范围并取得开发授权。

## 四层阅读顺序
1. 本目录：范围、需求、架构与待定决策
2. [子系统目录](../01-systems/README.md)：每个模块为何存在、拥有什么、不做什么
3. [详细设计目录](../02-detailed-design/README.md)：数据、状态机、算法、错误与测试合同
4. [执行入口](../03-execution/README.md)：任务依赖、文件责任、输入输出、验收证据与关口

## 1.0 非目标
多人、实时PVP、账号后端、交易市场、付费抽卡、云存档、无缝无限世界、家族生育、完整移动端适配。仅当验证表明有必要才启用Worker；不预建微服务。

## 修改流程
先定位[需求ID](requirements.md) → 修改详细设计与对应ADR → 更新任务/测试 → 检查原始设计是否受影响 → 人工评审后形成新基线。未通过的假设不写成用户已确认决策。
