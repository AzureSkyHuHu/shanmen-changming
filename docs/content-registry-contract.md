## API

- LEGACY_V7_CONTENT：深冻结的v7数据包
- RELEASE_V8_CANDIDATE：明确尚未上线的候选数据包
- contentIdentity/contentFingerprint：身份与包含全部游戏语义类别的组合摘要
- resolveContentIdentity：只解析内置注册ID与完全匹配的身份；默认拒绝候选，未知版本不回退当前版；访问器/异型输入失败关闭

候选包包含旧3+新8共11场遭遇、5路线、6训练+4奖励装备、24学习规则、3典籍、4招募模板、招募成本、复兴资源、首通规则和显式runtime/build/expedition/offer准入协议ID。文字模板与语言选择不进入模拟身份。

当前build-v2、expedition-v2与扩展准入仍标记pending。失衡额外目标、单人生还补员的World接入、旧历史迁移等阻塞全部保留；允许读取候选只是开发评估入口，不是发货许可。未来改动任一语义类别必须得到新的组合摘要并显式迁移，不手工保留旧摘要。

## 共享所有权

本模块由集成人维护。World负责把内容身份存入新档/新run并验证来源；UI只读取选定目录，不能上传或选择任意定义对象。永久build迁移应采用冻结旧前缀和版本化后缀，不能通过重建人物或清空收据“迁移”。

测试覆盖v7精确匹配、11场遭遇引用闭合、每类语义/协议修改均改变组合摘要、语言独立、未知/候选拒绝及深冻结。真实旧档回放和World迁移夹具将在接入时补齐。
