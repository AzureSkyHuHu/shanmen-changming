# v10 内部有限授课续行

日期：2026-10-02。范围：固定 v10 源的有限授课路线检查与精确候选重放；不注册 runtime、codec、migration、Session、UI 或玩家入口。旧 v9 文件与行为未改。

## 固定入口

`inspectTeachingContinuationV10(world)` 自行捕获并完整验证源，再调用 `assessManagementCapacityV10`。不接收调用者的容量证书、策略或验证回调。结果中的 `recoveryActions` 是在隔离候选上实际执行并验证过的玩家命令路线，既不会修改传入源，也不表示自动取消授权。外层真正发布每个命令或单刻仍须走完整准入。

教学双方必须在家、活着、无突破、死亡待决、培养活动、永久构筑锁、旅行或工作占用。师徒配对必须互不重叠，不接纳链、环、学生同时教学或已知相同知识。工作占用使用真实 `v10WorkOwners` 联合，包含升级工人；不能因升级没写旧 `assignmentTransactionId` 就把工人当空闲。

无关升级首先用真实 `upgrade.cancel` 取消；随后依次处理旧生产、图纸/建造、宗门生产、研究、护理、突破与可由玩家确认的寿尽待决。其他死亡原因不伪造确认，剩余所有者使路线失败。每个命令使用当前候选的修订和时钟，不复制假终态。

## 有界性与资金证明

- 命令数上界取开始时可取消的活跃所有者、计划/施工图纸、活跃突破及待决死亡数；每个实际候选必须严格减少该计数
- 命令 ID 统一避开当前及真实归档 World 回执、construction/production/research/care/upgrade 本地回执及培养回执；最多尝试已占 ID 数加一，既不使用无限重试，也不消费 RNG 或 World 编号
- 每次实际取消候选重新量完整 v10 容量，核对实际硬上限与缺口不增加，然后调用固定 `inspectReservedDischargesV10(before, after)` 验证既有义务的真实释放；只有拥有终态外观或少了 owner 不够
- 处理完全部无关工作后仍须核对工作联合、图纸、突破与待决死亡全空，且完整有限授课余量足够
- 未暂停时实际准备第一刻 `prepareNoOptionalGrowthTickCandidateV10`，核对两个时钟确实前进一刻，完整候选、实际上限及剩余余量均通过；已有暂停保留，不自行清除

时间沿用既有 phase-aware 有限证明：全部已付费剩余月份求和乘 1200，再只减一次当前月相位。并行授课仍取保守的月份和，真实月结可同时释放多个剩余月份。construction、production、research 的每刻修订仍各收完整该 horizon；护理及升级不被强行改成按空闲刻增修订。

升级的 400 **有效工作刻**不是 400 经过刻，也不是任意阻塞/维护等待的上界。路线先真实取消升级，仅使用已有取消回执/修订及有限记录峰值预留。取消后 no-op 升级阶段不增 revision；本片不额外发明 upgrade 的 400 刻或授课 horizon 修订收费。

## 教学候选的精确重放

`authenticTeachingTransitionV10(before, after)` 是完整根已认证来源的内部辅助。存在教学的变化需要与真实 v10 候选完整 canonical equality：

1. 双时钟前进一刻，只尝试固定正常/无可选增长两个真实单刻准备
2. 同刻命令变化，从真正新增的当前/归档 World 回执及五个本地命令域恢复候选；包括升级 start/cancel 回执
3. 用实际 `prepareUnregisteredCommandCandidateV10` 重放并比较整个 World

因此教学 ID、师徒、知识来源、月数、死亡清理、工人位置、付款及所有其他域同时绑定，不能靠修改计数器、伪造回执、删除教学或取消 owner 的局部变化充当证据。无教学的变化仍由完整容量/释放 gate 负责；该辅助不宣称认证所有非教学变化。
