# 胜利后返程寿尽

适用：v8 World 结算桥接；不修改冻结 v7 或 expedition-2/3 领域算法。

- 三场实际战斗胜利会封存 `victory` 结算。返程期间寿尽不倒改战斗记录、胜利原因、已封存战利品/损失及遭遇解锁标记。
- 战役通关与个人首胜要求至少一名队员活着归来。无人归来时仍须提交普通结算、清理远征锁、记录死亡及保存领域证据；不记战役首通，不开启相关首通领取资格，也不授予死者个人首胜。
- 寿尽先触发真实暂停，玩家确认死亡后才继续。全员死亡使用既有领域规则终止剩余返程；已预付月份不重复扣费或退款，遗产在解锁后一次结清。
- 结果页保留战斗胜利事实，同时列出实际幸存者与死者；战役页保持未通关。可补充“无人归来，不计战役通关/个人首胜”的说明，不能将胜利史料改为战败。

回归：`tests/integration/victory-return-mortality.test.ts` 在任何操作前明确构造年龄/出生刻一致的近寿尽边界，随后完成真实三场战斗、月度旅行、寿尽事件与死亡确认。覆盖返程月中/整月检查点全亡、一人存活、存读档、去重、装备遗产和原 v7 来源保持。该夹具不宣称实际模拟了完整一生；运行结果由集成负责人记录。
