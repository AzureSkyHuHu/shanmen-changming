# v10 私有实例的固定有界查询

## 范围

`runtime-instance-v10.ts` 接入已有的 v10 固定投影与查询验证器：

- `frame()`：场景、时钟、库存、人物与有限近期事件
- `cultivation(discipleId)`、`build(discipleId)`：有限选中对象；允许 `null`
- `expansion()`：真实 v10 工作、升级来源、维护期、配方与有限终态
- `previewBreakthrough(input)`、`previewPlacement(input)`、`previewUpgrade(input)`：只读条件预览
- `nextApplicationCommand(start)`：避开当前、归档和五类宗门回执的应用编号查询

没有注册新的 Session、React/Phaser 界面、公开引擎入口或存档路径。没有改变推进、命令、时钟控制、停止、发布和空闲证明的语义。

## 私有根与结果隔离

查询只接收固定小参数，不接收 World、候选、验证器、选择器、回调、缓存、价格、研究门槛或来源凭据。闭包当前根来自完整验证入口或独占保守空闲续行。查询不会创建命令准入证明，也不会以一个成功预览授权随后执行的命令。

每次先检查关闭/可重入状态，再对外部查询参数作有界描述符复制，随后调用对应固定验证器。外部 getter 不会执行；Proxy 反射仍可能执行调用者陷阱，不宣称可普遍识别所有 Proxy 或保证原子外部快照。捕获和投影失败均不读取外部异常的 `message`、原型或其他属性。

结果采用 `RuntimeReadV10<T>`，携带当前 stamp、停止状态、恢复专用标记和本次指标。成功的 DTO 及嵌套字段深冻结；固定投影分配所需展示对象，未在每帧描述符复制或导出完整 World。再次读取缓存只冻结小包装，不重新遍历已冻结 DTO。来源、外部请求及后续查询不会受返回对象的修改尝试影响。

合法查询返回 `ok: true` 不代表运行可以继续；已停止或恢复专用实例仍可读取当前状态。查询不改变 World、stamp、停止、恢复标记、命令回执或推进证明，也不会因为读取而重建精确容量锚。显示查询失败使用 `invalid-query` 或 `query-failed`；安全整数游标耗尽返回 `capacity`，不分配任何编号。

## 缓存合同

只有 `frame`、`cultivation`、`build`、`expansion` 四个固定槽位，最多 `RUNTIME_VIEW_LIMITS_V10.cacheEntries = 4` 条。人物槽只保留最新一个选择；大量不同 ID 不形成无限注册表。预览与编号查询不缓存。

每条缓存显式绑定当前私有根的对象身份、当前 generation 以及该槽位的参数。任何根替换（包括独占空闲捕获的等价新根）、实际刻/命令/时钟发布、成功 replace、invalidate 或 close 都清空缓存。未写入操作和失败查询保留仍匹配当前根/代次的旧结果；失败投影不能覆盖已有成功条目。旧 DTO 可供调用者保留，始终只是冻结的展示快照。

这里选择精确根绑定，不跨空闲刻保留内容恰好相等的 build/cultivation 身份。输出与缓存有界不代表叶查询总扫描成本、帧预算、20Hz、3倍速或移动端性能已通过。

## 测试与证据状态

新增 `tests/sect-expansion/v10-runtime-query-owner.test.ts`，覆盖：

- 实际 fresh、活动升级及完成 L2 根的八类 DTO 与固定叶逐项相等
- 深冻结、外部来源/请求隔离、不隐式导出 World 或重新做完整根查询
- 四固定槽位、重复读取、大量不同选择、真实空闲续行、真实命令与时钟发布刷新
- 未写入/失败操作、replace、invalidate、close、保留真实停止与恢复专用标记
- getter、非法 ID/对象/游标、外部权威字段、反射重入、敌意异常与失败缓存恢复
- 真实当前/归档回执搜索且不输出历史/预留/证明树
- 成功升级预览后实际暂停，再发命令仍由当前领域条件拒绝

升级夹具的旧记录由共享真实经营夹具取得；基础库存的显式资助属于测试准备。随后药性配伍、活动升级与完成 L2 均逐刻运行真实 v10 准备器，不手写升级终态，不声称执行了旧档迁移。

实现工作者未运行测试、类型检查、构建、基准或浏览器；由唯一集成者串行验证并补充最终结果。本文不把待执行断言写成通过证据，也不宣称新玩家入口或完整游戏验收。
