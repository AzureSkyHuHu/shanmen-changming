# v10 生产：固定领域候选阶段

日期：2026-10-02。状态：实现与测试用例已编写，实际验证由集成负责人串行执行；本文不声称尚未记录的检查已经通过。

## 本片边界

新增 `production-runtime-v10.ts` 与 `production-types-v10.ts`，保持旧 v9 生产入口、类型、配方白名单和校验器不变。输入为同步 v10 六域投影，输出仅为领域候选，不是 World、存档、迁移、护理或公开发布准入。

固定内部接口：

- `sectProductionSitesAtStartV10(frame, recipe, startedTick)` 查询历史开工时的有效等级；旧 L1 证明不会被今天 L2 的状态覆盖
- `sectProductionSitesV10(frame, recipe)` 查询当前站点并排除活动升级
- `validateSectProductionRecordsV10(frame, identities?)` 检查生产记录、历史站点、访问、工时、配对账本、导航、终态和升级生命周期互斥
- `validateSectProductionReceiptsV10(frame)` 保留精确命令、修订、去重和开工/取消归属验证
- `sectProductionClaimsV10(frame)` 返回该领域的工人、工位与入口占用
- `applyValidatedSectProductionCommandV10(frame, context, command)` 和 `tickValidatedSectProductionV10(frame, context, budget)` 为固定执行端口

完整根先认证描述符、单一建设/地图/人物/账本权威、维护、研究、升级、当前/归档生命周期，再调用固定阶段，并对全部候选、六域所有者和全存档余量一次准入。内部执行端口不重复调用缺少认证历史来源的局部校验器，因此不会仅因旧工人已真实归档而错误拒绝合法历史。`identities` 仅用于终态人物引用，不能创建当前工作者或赋予工作权限。

## 证明与执行

L2 证明必须为 placed，并绑定同一建筑、原建设 job、首次维护到期和精确完成升级 ID；有效等级来自已有升级记录查询。建设里的 level 始终是原始 L1。生产记录按自己的 startedTick 核对该证明，历史查询与当前可工作查询使用不同名称。

研究来源使用固定 v10 consumer 叶：基础伤药在 L1/L2 均绑定基础药理；替代方独立绑定药性配伍。替代方仅接受目录中精确 ID，预留草药 5、木 2，工作 200 有效刻，真实送仓后一次产出伤药 1，不用粮。基础方维持草药 3、粮 1、160 刻。没有客户端价格、等级、奖励或验证回调。

继续使用既有 `runProductionPhases`，包括真实移动、抵达边界不加工时、工位占用释放、送货和等待仓储、原子完成、仓满可取消。所有阶段使用同一调用者寻路预算。交付前固定检查当前站点、研究、历史等级、实际工时的付费区间及升级互斥；输入仅在真实成功交付时消耗。

生产与升级按完整生命周期互斥，送货途中和 AwaitingDelivery 都算未终态生产。生产真正终止的同一边界允许随后开始升级；升级完成的同一边界允许随后开始 L2 生产。使用两个同步时钟和真实终态，不比较不同领域的 revision 大小来猜测先后。

保留原生产校验中的精确字段、ID、工人引用、工位/仓库、访问位置和曼哈顿最短旅行时间、工时区间合并/顺序/总数、维护付费区间、配对预约价格、导航形状、活动占用、完成/取消结算以及命令回执检查。v10 另要求两个管理时钟相同；域内记录与容量仍有限且不清除历史。

## 测试范围

`tests/sect-expansion/production-v10.test.ts` 是明确标识的领域夹具：仅基础库存采用有界资助；灵石、心得、两个研究、藏经阁与丹房、L1 药、400 刻升级及 L2 药都通过真实现有/新领域 reducer 逐刻执行。旧域先经过原严格准入；新域在关键边界经过固定记录叶，未冒称缺失的完整根、迁移或 UI 已运行。

用例覆盖：

- 历史 L1 证明在真实后续升级后原样保留，生产终止→升级开工和升级完成→L2 开工均精确同刻
- 真实 L2 替代药、零粮、草药 5/木 2、200 有效刻、真实交付、独立药性配伍引用
- L2 基础伤药继续使用基础药理与旧 160 刻费用
- L1 拒绝替代方、当前活动升级不可用、错误来源/完成 ID/等级/研究引用拒绝
- 送货和等待送货全生命周期互斥、仓满保留输入且可以取消、交付时重新核验固定来源
- 原工时、导航、账本价格、回执、送货与终态损坏拒绝；精确重试、输入不变与不同领域修订大小无关
