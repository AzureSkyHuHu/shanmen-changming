# v10 私有存档面板适配器

日期：2026-10-03。此文记录私有组件范围，不代表公开入口已启用或浏览器验收完成。

## 接入边界

- `createManagementStorageSlotV10(controller)` 将真实 `ManagementSaveControllerV10` 适配为 `ManagementAppV10` 的 `subscribe/getSnapshot/renderBody` 插槽
- 构造和服务端呈现不启动控制器、不打开数据库、不导出 World、不修改 Session 暂停。入口负责控制器 `start/stop` 和 Session 生命周期
- 父组件继续独占原生 dialog、标题、关闭按钮、页脚反馈、Tab 焦点限制和 overlay hold。适配器只返回滚动区域内容；内部确认使用当前模态内的控件
- 未接默认入口、未访问 v9 数据库、未执行 v9 迁移，也不接复制转换协调器。来源备份导出只读 v10 仓库已保留的原始备份

## 真实状态与确认

- 显示实际绑定位置、dirty、manual-only、readOnly、最近成功时间、每槽精确 revision、可恢复/不可读取状态，以及已写入但未绑定的 durable receipt
- 时间统一复用既有日期帮助函数，按当前选择的 locale 格式化并显示本地时区偏移；非法时间显示翻译后的未知时间
- 手动保存仍由 `canSave` 和真实控制器限制：陌生已占用位置须先读取，不能直接保存覆盖
- 读取保留真实控制器 `LoadReviewV10` 对象身份、精确槽 revision 和完整 Session 边界；dirty 替换有独立勾选。确认先消耗本地意图，重复点击不会重复提交
- 文件输入为原生 `input type=file`，仅调用严格 v10 控制器，4 MiB 与版本验证在控制器内。不能把 HTML accept 属性当成验证
- 导入保留 selectionId、目标 slotId/revision/occupied、dirty 及完整 Session epoch/worldRevision/revision/stamp/selection/resourceStamp。覆盖槽位和丢弃未保存进度分别勾选。重新选文件、选目标、取消或边界变化使旧确认失效
- 读取确认与显式重新核对会将焦点移到首个可用确认控件；原生目标下拉框保持键盘选择焦点，不在每次方向键变更后强行跳转。取消时只向仍挂载、同一 Session/epoch/选择且未忙碌的原控件或文件输入返回焦点；不抢走用户已移到其他控件的焦点。确认区域的 Escape 取消内部核对，不直接关闭父弹窗
- 只使用真实布尔返回值和返回的文件描述符。拒绝、异常、缺少备份、晚到结果不能伪报成功；同步双击和旧挂载回调被隔离。错误按当前操作分流：旧文件导入的版本错误不会遮盖后续保存的配额/租约错误或原文导出的缺失/事务错误

## 导出和反馈

- 当前会话导出调用控制器当前快照出口，即使浏览器存储不可用也可尝试；不会因此把 dirty 清零
- 已保存位置列出 manifest 中去重的原始快照，包括无法读取或未支持的新版本。导出内容按原文保留，不解析后重写、不宣称已成功加载
- 每槽来源备份按钮调用 `exportMigrationSource`。普通存档可能没有备份，此时显示真实失败；该按钮不创建备份、不进行迁移
- 复用既有 `SaveFile` 描述符和 Blob/anchor 下载模式，替换、卸载及失败（包括尚未成功构造 anchor）时撤销所拥有的对象 URL。“已准备下载”只表示触发下载请求，不保证用户已将文件保存到设备
- 私有稳定文案键使用项目参数校验器及逐键中文回退。父页脚仅接受已有文本键，因此屏蔽旧“导入不改变当前进度”句子；实际导入/读取成功说明在正文明确保留保存文件原有暂停状态
- lease 文案不建议此控制器不具备的强行接管操作。已写入但未绑定的 receipt 仅作为历史事实：写入已完成，当时尚未绑定，写入并未回滚。不会声称当前仍未绑定，也不要求再次读取。控制器没有公开 Session 的精确绑定 revision，刷新后的 manifest revision 不能证明某个历史 receipt 已绑定；因此面板完全不推断这类“已解决”状态，仍保留普通刷新/读取控件
- stopped 只说明不再接收新操作，不把异步关闭/租约清理尚未完成误写为数据库已经关闭
