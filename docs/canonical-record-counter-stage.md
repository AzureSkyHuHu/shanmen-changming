# 规范记录三维计量

## 本片范围

新增 `src/core/save-budget/canonical-records.ts`，一次递归计量规范 JSON 的 UTF-8 字节、UTF-16 字符单元和解码值节点。对象键不计节点，共享子树的每次出现仍收取完整大小。字符串转义、合法代理对、孤立代理单元、有限数字与负零的拼写，以及对象/数组标点，与现行规范序列化一致；不构造完整规范 JSON 文本。

窄接入仅将 `measureProgressionRecord` 的函数体委托给三维计量器，并保留原导出名和返回类型。其余成长容量公式、调用者、领域验证、旧字节计量器、存档格式与玩家入口不变。本片不授予状态发布或存档准入权限，也不代表活动工作或整局性能达标。

## 输入与身份复用边界

- 只接受普通原型、可枚举自有数据属性、有限 JSON 叶值和普通稠密数组；拒绝访问器、符号/隐藏属性、定制数组、稀疏数组、循环及非 JSON 值
- 子值和数组长度只从捕获的数据描述符取得，不先检查描述符再对外部对象做普通属性读取。每个容器在递归子项前捕获全部自身描述符
- 私有 WeakMap 仅复用本计量器递归检查过的完全冻结子树。先观察对象不可扩展，再以不可配置且不可写的描述符和全部子项认证；不信任浅冻结、调用者标记或自带计数，不冻结或改写调用者对象
- 可变输入每次出现使用当次描述符快照。反射期间的敌意重入可以改变后续快照，不能令已捕获数据变为 getter 读取或把可变快照认证进持久缓存。便携 JavaScript 无法识别所有 Proxy，也不能阻止其反射陷阱执行；本片不声称能做到
- 缓存命中仍检查当前对象的形状/原型，因此已缓存对象本身若是后来被撤销的 Proxy，会拒绝计量，与旧字节计量器的顶层检查一致。但不会重新遍历缓存根的子项：若普通冻结根下面的 Proxy 在认证后被撤销，该根仍返回原有大小快照；新计量器或旧三遍实现的实时子遍历则会拒绝。缓存不提供持续有效的递归访问或实时状态认证
- 计数加法超过安全整数范围时拒绝；返回的计数及统计对象与内部缓存分离。统计只用于临时观测，不能成为存档或玩法权威

## 等价性范围与明确修正

与旧 `measureProgressionRecord` 的等价性针对普通、可枚举的解析 JSON 和领域数据，不针对任意 JavaScript 对象。测试保留旧三遍实现的独立副本作差分基准，不能把更新后的包装函数当作自己的唯一预期值。

旧实现对非可枚举数组元素有内部不一致：字节计量和规范序列化包含元素，`Object.values` 节点遍历却省略该元素。例如隐藏索引的 `["hidden"]` 曾得到字节10、字符10、节点1；解析相同 JSON 后应有节点2。新入口明确拒绝这种描述符形状，不延续不一致的节点结果。普通 JSON 解析和正常领域记录不会产生隐藏数组索引。

另有审阅回归覆盖：可扩展 Proxy 原有固定属性 a，读取其描述符时添加固定属性 b 并禁止扩展。第一次捕获的 `{a}` 不缓存；第二次重新捕获 `{a,b}` 才可认证，避免反射中途冻结导致漏计的身份复用。
